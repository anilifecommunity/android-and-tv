Anilife separates episode alerts from project announcements, so you can enable the messages you want and control each Android notification channel.

## Notification settings

Open **Settings → Notifications**:

- **Notification alerts** shows AniList notifications when you are signed in, or release alerts for saved anime when you are signed out.
- **Announcements** shows rare Anilife notices such as an outage, a release warning, or a moved official download.

On Android 13 or newer, the system notification permission must also be granted. If the in-app switch is on but nothing appears, check **Android Settings → Apps → Anilife → Notifications**.

## Announcement behaviour

Announcements appear as Android notifications and open inside Anilife when tapped, so you can read the full message and inspect any link before opening it. Routine and urgent announcements use separate Android channels. You can silence either channel in the system settings.

<Note>
  Anilife announcements are occasional project messages, not advertising. If no current notice applies to your installed version, nothing is shown.
</Note>

## Missing alerts

1. Confirm the relevant in-app switch is enabled.
2. Confirm Android notification permission is enabled.
3. Check whether battery or background restrictions are delaying work.
4. Open Anilife once with a network connection.
5. If the problem continues, export diagnostics and include the approximate time an alert should have appeared.
