Anilife provides separate touch and television builds so each device gets the correct navigation and playback experience. Choose the universal APK when you are unsure whether the device uses 64-bit or 32-bit ARM.

## APK selection

| Device | Preferred APK | Fallback |
| --- | --- | --- |
| 64-bit ARM phone or tablet | `Anilife_arm64-v8a.apk` | `Anilife.apk` |
| 32-bit ARM phone or tablet | `Anilife_armeabi-v7a.apk` | `Anilife.apk` |
| 64-bit ARM television | `Anilife_tv_arm64-v8a.apk` | `Anilife_tv.apk` |
| 32-bit ARM television | `Anilife_tv_armeabi-v7a.apk` | `Anilife_tv.apk` |

Universal APKs include both supported ARM architectures. They use more download space but avoid architecture guesswork.

## Device guidance

<AccordionGroup>
  <Accordion title="Android phones and tablets">
    Use a phone/tablet APK. These builds use touch-first, edge-to-edge navigation and support Android 5.1 or newer.
  </Accordion>

  <Accordion title="Android TV and Google TV">
    Use a TV APK. Transfer the APK with your normal file-transfer method or open the official Releases page in a trusted browser, then allow installation from that source.
  </Accordion>

  <Accordion title="Fire TV">
    Use a TV APK. Compatible Fire OS 5 devices are supported. You can open the official GitHub Releases page in a trusted downloader browser or sideload the APK from a computer.
  </Accordion>
</AccordionGroup>

<Warning>
  Do not install a phone APK on a television just because it is smaller. The TV build provides the remote-first interface and form-factor-specific update path.
</Warning>

## Playback locks and external players

The lock button in Anilife's player prevents accidental touch, remote and Back-button input until
you unlock the controls. It is not a security lock. To keep another person out of a profile, set
its four-digit PIN under **Settings → Profile lock** instead.

The built-in player is the default. You can hand one episode to another installed player from the
player settings, or enable **Settings → Player → Open episodes in external player** for every
episode. Compatible apps such as mpvEx, mpv-android and VLC appear through Android's normal video
app picker. Anilife can pass remote or downloaded video, subtitles and a resume position; the
receiving player decides which of those it supports and whether it reports progress back.

mpvEx users can configure Anime4K or their own mpv shaders in mpvEx. This is real-time image
enhancement, not a native 4K source, and it can use more battery and GPU power. Anilife does not
apply a second upscaler before handing the video over.

If something fails only on one episode source, it may be a provider problem rather than device incompatibility. Include the device model, Android or Fire OS version, selected APK, and whether every source is affected when you report a problem.
